# Project knowledge index

## Rydberg optimal control

- `jandura2022timeoptimal` — time-optimal CZ and C2Z gates, smooth pulse
  ansätze, finite-blockade and Rydberg-decay analysis. External source:
  <https://doi.org/10.22331/q-2022-05-13-712>. Local TeX source, when present:
  `.raw/arxiv/2202.00903/source.tex`.
- `hu2025universal` — globally controlled analog simulators and direct quantum
  optimal control. External source: <https://arxiv.org/abs/2508.19075>. Local
  TeX source, when present: `.raw/arxiv/2508.19075/source.tex`.

# TFIM adiabatic manuscript

This directory is the root of the TFIM/Rydberg theoretical notebook, paper
draft, round reports, and slides. It contains project-owned LaTeX and the
durable theoretical work that supports the implementation. It is distinct
from:

- `docs/`, which explains the software and its architecture;
- `.knowledge/`, which indexes external literature;
- `results/`, whose README files are the complete records of numerical runs.

The research flow is:

| Stage | Canonical location |
|---|---|
| Durable derivation or paper text | `manuscripts/notes/` or `manuscripts/chapters/` |
| Reusable implementation | `src/` |
| Concrete numerical workflow | `scripts/` |
| Run evidence and interpretation | `results/<run>/README.md` |
| Selected narrative and figures | `manuscripts/` |

Do not add another manuscript directory or Git repository below this one.

## Structure

- `main.tex` — book-style primary draft.
- `chapters/` — manuscript chapters and canonical derivations.
- `reports/main.tex` and `reports/Reports_R1.tex` — report material.
- `pre/slide.tex` — presentation source.
- `figures/` — curated, tracked manuscript figures.
- [`../.knowledge/references.bib`](../.knowledge/references.bib) — shared
  bibliography for this repository.

`chapters/Rydberg_sim.tex` is the canonical derivation for the multilevel and
effective Hamiltonians implemented in `src/ryd_gate/core/effective_theory.py`.
Code and physics tests refer to this path directly. Future durable calculations
that guide implementation but are not ready for the draft may start in
`notes/`; temporary AI scratch work stays in `.agents/work/`.

## Result-to-paper workflow

Generated arrays, checkpoints, logs, and exploratory plots remain under
`results/` and stay local. Copy only a publication-ready figure into a
`figures/`, then record the originating results README and generating script
immediately before its `\includegraphics`:

```tex
% Source: results/<run>/README.md; generated by scripts/<script>.py
```

Do not make the manuscript depend directly on ignored files under `results/`.
The figures imported with this pre-existing manuscript do not yet have
repository result provenance; keep them as legacy assets until each is
regenerated or traced rather than inventing a source record.

## Build

On Ubuntu, install the toolchain system-wide so every user can compile the
manuscript:

```bash
sudo apt-get update
sudo apt-get install -y \
  latexmk biber \
  texlive-latex-base texlive-latex-recommended texlive-latex-extra \
  texlive-science texlive-fonts-recommended texlive-bibtex-extra
```

Then compile from this directory so the shared bibliography and figure paths
resolve consistently:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error -outdir=build main.tex
```

This command was verified with the system-wide TeX Live 2025, Latexmk 4.87,
and Biber 2.21 packages, as well as a user-local TeX Live 2026 installation.

### Cursor Remote

The tracked workspace settings select the same `latexmk` command and write its
output to `manuscripts/build/`. LaTeX Workshop's macOS build shortcut is
`Command+Option+B` by default. To use `Command+B`, open **Preferences: Open
Keyboard Shortcuts (JSON)** in the local macOS Cursor client and add this entry
to the surrounding JSON array:

```json
{
  "key": "cmd+b",
  "command": "latex-workshop.build",
  "when": "editorLangId == latex && !virtualWorkspace"
}
```

Keyboard shortcuts belong to the local Cursor client, whereas the compiler and
the workspace settings run on the remote Linux host.

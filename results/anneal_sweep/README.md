# anneal_sweep — TFIM 退火协议扫描，以及 PEPS 键维是否收敛

## 问题与模型

Rydberg 阵列上退火出横场 Ising 序，读出 Rydberg 密度 $n_r(t)$ 与交错磁化 $m_s(t)$。
自然单位取 $w_0 = V_{\rm nn}/24$，最近邻相互作用给出 $J = 6w_0$：

$$H(t) = h_x(t)\sum_j X_j \;-\; h_z(t)\sum_j Z_j \;+\; J\sum_{\langle jk\rangle} Z_jZ_k$$

协议是三段（升 / 保持 / 降），$t_{\rm rise}=t_{\rm fall}=2/w_0$：

$$h_x:\;0 \to h_x^{\rm peak}\ \text{(线性升)} \to \text{平台} \to 0,
\qquad
h_z:\;h_z^{i}\ \text{(保持段内线性降到 0)}$$

其中 $h_z^i = 24w_0$ 正是 $\Delta = 0$ 的经典相边界，$>24$ 则从有能隙的平庸相出发。
标准点为 $h_z^i=24w_0$、$h_x^{\rm peak}=1w_0$、$t_{\rm hold}=12/w_0$。

这里有两件事必须先分清，否则读出的一切都是数值而非物理：

- **Trotter 误差**（$dt$）与**截断误差**（键维 $D$）会互相掩盖；
- 3×3 上 $D=8$ 已无截断，所以该尺寸下的残差**纯粹是 Strang 误差** —— 这正是校准脚本
  用来把两者拆开的杠杆。

## 核心结果

### 键维阶梯：$D=6$ 不可用，$D=10$ 收敛

标准点 $(h_z^i,h_x^{\rm peak},t_{\rm hold}) = (24,1,12)$，末态交错磁化 $m_s(T)$
（$m_s$ 的真值应为 0，任何非零都是数值残余）：

| | $D=6$ | $D=8$ | $D=10$ |
|---|---|---|---|
| $m_s(T)$ | **0.180** | $-8.65\times10^{-4}$ | $6.86\times10^{-6}$ |
| $\max n_r$ | 0.635 | 0.543 | 0.522 |

**三个数量级的差距全部来自键维**。$D=6$ 的 0.180 不是"略有偏差"，而是把一个应当为零的
序参量报成了 0.18；同时 $\max n_r$ 随 $D$ 单调下降，说明 $D=6$ 在**过度有序**。

### $dt$ 更细反而更糟 —— 这条最反直觉

同一点把 $dt$ 从 $0.1/w_0$ 减半到 $0.05/w_0$，$D$ 仍为 6：

| $dt/w_0$ | $m_s(t)$ 末段行为 | $\max n_r$ |
|---|---|---|
| 0.1 | 单调爬到 0.180 | 0.635 |
| **0.05** | **在 $\pm0.9$ 之间振荡**（$-0.353,\,-0.808,\,+0.843,\,-0.899,\,+0.903$） | **0.993** |

更细的时间步只是把**截断**误差解析得更清楚，并不会消除它 —— Trotter 误差原本还在
"盖住"截断误差，$dt$ 一细，截断误差就暴露成剧烈振荡。所以：
**$D=6$ 的数字只能当作误差的下界，永远不能当作结果引用。**

（另有记录：$dt=0.2/w_0$ 已被否决 —— $V\,dt\approx 4.8$ rad 的 Trotter 门把末态密度
从 0.42 压到 0.23。）

### 校准锚点

`calibration_3x3.npz` 把**一次 exact_ode 参考解**（DOP853，rtol 1e-10）与整条 PEPS 阶梯
放在同一个文件里，所以比较是直接的而非跨文件拼的：

- **Trotter 分支** — $D=8$ 固定，$dt/w_0\in\{0.1,0.05,0.025\}$：$D=8$ 在 3×3 无截断，
  残差即 Strang 误差（$dt=0.1$ 的地板约 $4.5\times10^{-2}$，$dt=0.05$ 约 $4.5\times10^{-3}$）。
- **截断分支** — $dt=0.05/w_0$ 固定，$D\in\{2,3,4,6\}$：此时 Strang 误差已经小到
  不再淹没截断误差。
